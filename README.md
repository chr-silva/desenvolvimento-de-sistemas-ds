# 💻 Desenvolvimento de Sistemas - IFPA

Bem-vindo ao repositório oficial do site da turma de **Técnico em Desenvolvimento de Sistemas** do **Instituto Federal do Pará (IFPA)**!

Este projeto apresenta a estrutura do curso, disciplinas estudadas, a infraestrutura do nosso campus (o famoso **Bloco C**) e uma vitrine com os projetos desenvolvidos pelos estudantes da turma.

---

## 📌 Sobre o Curso

O curso Técnico em Desenvolvimento de Sistemas capacita os estudantes a projetar, desenvolver, testar e manter softwares, soluções web/mobile e bancos de dados. A formação alia fundamentação teórica com prática desde os primeiros períodos.

### 📚 Matérias e Aprendizado
* **Algoritmos e Lógica de Programação:** Introdução ao pensamento estruturado e manipulação de dados utilizando C++.
* **Programação Orientada a Objetos (POO):** Construção de sistemas modulares e escaláveis utilizando Java e Python.
* **Banco de Dados:** Modelagem e manipulação de dados com linguagem SQL.
* **Desenvolvimento Web e Mobile:** Criação de interfaces e aplicações interativas para navegadores e dispositivos móveis.
* **Redes de Computadores e Hardware:** Infraestrutura, comunicação de dados, conectores, switches e roteadores.

---

## 🏛️ Infraestrutura: Bloco C

O **Bloco C** é o centro das atividades do curso no IFPA, contando com:
* 💻 **5 Laboratórios de Informática** equipados.
* 🎙️ **2 Mini-auditórios** para aulas, seminários e apresentações.
* ❄️ Ambientes climatizados para estudos e desenvolvimento de projetos.
